Что внутри

Аудит публичных страниц

Title, description, H1, canonical, Open Graph, Twitter Card, Schema.org, изображения без alt, robots и sitemap.

Отчеты для людей

JSON для автоматизации, Markdown для обсуждения и HTML для демонстрации клиенту.

Lighthouse без ручного запуска

Агент сам запускает Chrome/Lighthouse и добавляет Performance, SEO, Accessibility, Best Practices и lab metrics в отчет.

Safe-fix workflow

Правки делятся на безопасные, требующие approve и ручные рекомендации.

Связка с uCoz

Официальный ucoz-mcp читает шаблоны, страницы и FTP-файлы, а SEO MCP делает аудит и safe-fix план.

Как подключить официальный MCP uCoz

Установка

Добавьте SEO MCP в Codex
[mcp_servers.ucoz-seo-audit-fix]
command = "npx"
args = ["-y", "--package", "https://seoaudit.ucoz.net/seo-mcp/ucoz-seo-audit-fix-0.1.0.tgz", "ucoz-seo-audit-mcp"]
startup_timeout_sec = 60
Подключите официальный uCoz MCP

Если официальный MCP еще не настроен, откройте инструкцию uCoz по подключению MCP.

[mcp_servers.ucoz]
command = "npx"
args = ["-y", "ucoz-mcp@latest"]

[mcp_servers.ucoz.env]
UCOZ_API_TOKEN = "sk_live_..."
UCOZ_SITE_URL = "https://your-site.ucoz.net/"
UCOZ_FTP_HOST = "your-site.ucoz.net"
UCOZ_FTP_USER = "..."
UCOZ_FTP_PASS = "..."
Перезапустите MCP в клиенте
После сохранения конфига Codex/Cursor/Claude сам скачает пакет и запустит MCP.

Как работает

1. Audit

audit_site сканирует сайт и создает отчет с группировкой по страницам.

2. Lighthouse

run_lighthouse_audit снимает performance/SEO-сигналы через Chrome без ручной проверки.

3. Fix & verify

Официальный ucoz-mcp применяет точечный diff, затем аудит запускается повторно.

Важно про безопасность

Не кладите реальные API-ключи и FTP-пароли в публичные архивы. Этот пакет не содержит секретов: каждый пользователь подключает свой сайт локально в MCP-клиенте.
